## Project notes
- Node 26 runs `.ts` files directly (no build step); `npm run typecheck` checks types. Avoid TS-only runtime syntax (enums, constructor parameter properties).
- `helper/vision-helper.swift` is compiled with the Command Line Tools (`npm run build:helper`) into `bin/` (gitignored). It captures in memory with ScreenCaptureKit and reads text with Vision; Node talks to it via JSON lines (`src/helper.ts`).
- `sessions/` holds terminal-session transcripts and is gitignored (personal data).
- App: electron-vite (vite 7; electron-vite 5 doesn't support vite 8). Database is Node's built-in `node:sqlite` (works in Electron 44, so no better-sqlite3). Preload is built as CommonJS (sandboxed).
- Dev checks: `GLOSS_DB=<temp.db> GLOSS_SMOKE=<dir> npx electron-vite preview` screenshots both windows; `GLOSS_SMOKE_SESSION=<seconds>` records a real session with a pause. Always use a throwaway `GLOSS_DB`.
- Launched from a terminal, the app inherits that terminal app's Screen Recording permission.
- Dev checks with `GLOSS_DB` get their own data folder and skip the single-instance lock, so they can run beside the user's copy. `GLOSS_SMOKE_REVIEW=<dir>` makes the newest session's summary + quiz with the real model.
- Math reading: glm-ocr:q8_0 (0.9B document OCR, ~58 tokens/s, ~5 s per crop) via `readMathParagraphs`: prompt "Text Recognition:", streamed and stopped at the first repeated line; whole paragraphs replaced via `alignParagraphs` (strongest matches first, letters+digits agreement ≥ 0.6). Patching Apple's lines with qwen was slow and mostly rejected.
- UI style "calm study desk" (user's spec, 2026-10-14; replaced "study notebook"): exact colours as CSS tokens in index.css (light paper #FAFAF7 / card #FFF / ink #1C1C1E / muted #6E6E73; dark #1C1C1E / #2C2C2E / #F5F5F7 / #98989D; accent indigo #5B5BD6 only for primary buttons, highlights and the recording dot; good #30A46C, bad #E5484D). SF Pro (system font) for UI, `.New York` serif (`font-serif`) for headings and reading text. Shared Tailwind `@utility` classes: `card`, `eyebrow`, `btn-primary/secondary/ghost/danger`, `field`, `chip`, `appear` (180 ms fade + 4 px slide). Links/labels are neutral (not indigo). Summaries are plain-notation math converted for display by `plainMathToLatex` (formatting only; handles `2^(k-1)`, `f_(k+1)`).
- Design check: `node scripts/seed-demo-db.ts <new.db>` makes a made-up demo database; `GLOSS_THEME=light|dark GLOSS_DB=<demo.db> GLOSS_SMOKE_DESIGN=<dir>` screenshots every screen (add `GLOSS_SMOKE_EMPTY=1` with an empty DB for the empty states). Screenshots aren't kept in the repo (user deleted them); regenerate when needed. Windows reload on hash change (a reused review window opened at the quiz).
- KaTeX must stay on the same version rehype-katex uses (0.16.x; check `npm ls katex`): a newer KaTeX CSS draws fraction bars through the numbers. CSP allows `font-src 'self' data:` because vite inlines small KaTeX fonts.
- Stage 4 (circle and ask): `src/main/ask.ts`. Shortcut from settings.json (`ask.shortcut`, default "Alt+A" = Option+A) via Electron globalShortcut — no keyboard monitoring (user turned off Input Monitoring; don't add event taps). Overlay = transparent "panel" window preloaded at session start; cursor path polled at 60 Hz; click or the shortcut again sends, Esc cancels. Overlay must vanish (setOpacity 0) + 150 ms before `helper.snap`, or the capture is black. Crop logic in `src/core/crop.ts`. `withModel` in ai.ts serializes all AI calls and unloads other models (never two loaded; keep_alive 3m); work inside `urgently()` (asking) goes ahead of waiting background jobs like math re-reads. In React effects, never return a value (scrollIntoView returns a Promise now). `GLOSS_SMOKE_ASK=<dir>` runs the whole flow with a pretend circle.
- Voice (Stage 4 step 2): `helper/voice.swift` → `bin/Gloss Voice` (embedded Info.plist with mic + speech usage strings, ad-hoc signed as com.daviddeng.gloss.voice). It must be started via `vision-helper --disclaim <path>` so macOS treats it as its own responsible app (VS Code/Electron lack NSSpeechRecognitionUsageDescription → would be killed). On-device only (`requiresOnDeviceRecognition`). Rebuilding the voice binary may make macOS ask for its permissions again. Snap can return solid black right after the overlay closes → helper reports `black`, ask.ts retries.
- Stage 5 learner model: rules in `src/core/learner.ts` (mastery from evidence; fades with a half-life that doubles per correct answer; never store mastery, compute it). Concepts come from summary points (`concept` field, reusing known names); quiz questions get concept ids from the model, else `LearnerService.tagQuestions` (passage → concept). Quiz retries once if < 5 survive checking. Course memory: `src/core/memory.ts` (keywords now; embeddings via `embeddinggemma` once downloaded — `LearnerService.backfillEmbeddings`). Smoke: `GLOSS_SMOKE_LEARN=<dir>` (seed a DB first), `GLOSS_SMOKE_ASK` with `GLOSS_SMOKE_COURSE` / `GLOSS_SMOKE_QUESTION`.
- "Find it" (search everything captured): migration 5 adds FTS5 table `chunks_fts` (own copy of text, title, app + chunk_id), filled from existing chunks and kept in step by triggers on `chunks` (they also fire on cascade deletes). `chunks.fts_rowid` links a chunk to its index row (chunks has no INTEGER PRIMARY KEY, so its rowid could change on VACUUM).
