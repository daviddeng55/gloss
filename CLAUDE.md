## Project notes
- Node 26 runs `.ts` files directly (no build step); `npm run typecheck` checks types. Avoid TS-only runtime syntax (enums, constructor parameter properties).
- `helper/vision-helper.swift` is compiled with the Command Line Tools (`npm run build:helper`) into `bin/` (gitignored). It captures in memory with ScreenCaptureKit and reads text with Vision; Node talks to it via JSON lines (`src/helper.ts`).
- `sessions/` holds terminal-session transcripts and is gitignored (personal data).
- App: electron-vite (vite 7; electron-vite 5 doesn't support vite 8). Database is Node's built-in `node:sqlite` (works in Electron 44, so no better-sqlite3). Preload is built as CommonJS (sandboxed).
- Dev checks: `STUDY_BUDDY_DB=<temp.db> STUDY_BUDDY_SMOKE=<dir> npx electron-vite preview` screenshots both windows; `STUDY_BUDDY_SMOKE_SESSION=<seconds>` records a real session with a pause. Always use a throwaway `STUDY_BUDDY_DB`.
- Launched from a terminal, the app inherits that terminal app's Screen Recording permission.
- Dev checks with `STUDY_BUDDY_DB` get their own data folder and skip the single-instance lock, so they can run beside the user's copy. `STUDY_BUDDY_SMOKE_REVIEW=<dir>` makes the newest session's summary + quiz with the real model.
- Math reading: glm-ocr:q8_0 (0.9B document OCR, ~58 tokens/s, ~5 s per crop) via `readMathParagraphs`: prompt "Text Recognition:", streamed and stopped at the first repeated line; whole paragraphs replaced via `alignParagraphs` (strongest matches first, letters+digits agreement ≥ 0.6). Patching Apple's lines with qwen was slow and mostly rejected.
- UI style "study notebook" (user chose): `.SF NS Rounded` for UI/headings, `.New York` serif for reading text (Electron only knows these internal names), warm paper palette + terracotta accent as CSS vars in index.css (`bg-paper`, `bg-card`, `text-ink`, `text-muted`, `accent`). Summaries are plain-notation math converted for display by `plainMathToLatex` (formatting only).
- KaTeX must stay on the same version rehype-katex uses (0.16.x; check `npm ls katex`): a newer KaTeX CSS draws fraction bars through the numbers. CSP allows `font-src 'self' data:` because vite inlines small KaTeX fonts.
- Stage 4 (circle and ask): `src/main/ask.ts`. Shortcut from settings.json (`ask.shortcut`, default "Alt+A" = Option+A) via Electron globalShortcut — no keyboard monitoring (user turned off Input Monitoring; don't add event taps). Overlay = transparent "panel" window preloaded at session start; cursor path polled at 60 Hz; click or the shortcut again sends, Esc cancels. Overlay must vanish (setOpacity 0) + 150 ms before `helper.snap`, or the capture is black. Crop logic in `src/core/crop.ts`. `withModel` in ai.ts serializes all AI calls and unloads other models (never two loaded; keep_alive 3m). In React effects, never return a value (scrollIntoView returns a Promise now). `STUDY_BUDDY_SMOKE_ASK=<dir>` runs the whole flow with a pretend circle.
- Voice (Stage 4 step 2): `helper/voice.swift` → `bin/Study Buddy Voice` (embedded Info.plist with mic + speech usage strings, ad-hoc signed as com.studybuddy.voice). It must be started via `vision-helper --disclaim <path>` so macOS treats it as its own responsible app (VS Code/Electron lack NSSpeechRecognitionUsageDescription → would be killed). On-device only (`requiresOnDeviceRecognition`). Rebuilding the voice binary may make macOS ask for its permissions again. Snap can return solid black right after the overlay closes → helper reports `black`, ask.ts retries.
- Stage 5 learner model: rules in `src/core/learner.ts` (mastery from evidence; fades with a half-life that doubles per correct answer; never store mastery, compute it). Concepts come from summary points (`concept` field, reusing known names); quiz questions get concept ids from the model, else `LearnerService.tagQuestions` (passage → concept). Quiz retries once if < 5 survive checking. Course memory: `src/core/memory.ts` (keywords now; embeddings via `embeddinggemma` once downloaded — `LearnerService.backfillEmbeddings`). Smoke: `STUDY_BUDDY_SMOKE_LEARN=<dir>` (seed a DB first), `STUDY_BUDDY_SMOKE_ASK` with `STUDY_BUDDY_SMOKE_COURSE` / `STUDY_BUDDY_SMOKE_QUESTION`.
- AI: Ollama + qwen3.5:4b, ~16 tokens/s. Quiz = makeQuiz (8 questions, no thinking) then verifyQuestions (drops unsupported ones; keep "problem" short or it rambles). Thinking mode was too slow. Forcing LaTeX in summaries made the 4B model write wrong math, so summaries use plain notation; quiz questions/answers do use $...$. Models write LaTeX with single backslashes inside JSON: `fixLatexEscapes`.
